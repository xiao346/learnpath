# 计算机网络长文图解改写

## 本批范围

计算机网络课程的 8 章已经使用连续图文教程替换旧的“生活类比 + 六张知识卡片”展示。共 55 个讲解小节、18 处原理图（15 种图形机制）。其余 50 章仍保留原版本，不计入本批完成范围。既有学习进度与练习数据没有被清空，也没有替用户标记章节完成。

## 讲解方法

参考用户提供的[小林 coding TCP/IP 模型讲解](https://xiaolincoding.com/network/1_base/tcp_ip_model.html)观察“提出问题、拆开过程、画出关系、结合例子解释”的组织方法。本文与 SVG 均为原创，没有复制网站正文或图片。协议准确性另外通过正文附带的 RFC、Cisco 技术说明与 MIT 课程资料核对。

正文围绕具体问题展开，先交代对象与假设，再解释机制和结果。图使用信号波形、网络拓扑、报文时序、字节范围、地址块等知识本身的形状；颜色和箭头都有含义，图下注释解释省略条件和常见误解。不会以一幅装饰插画代替机制讲解。

可逐步演示 TCP 分段与缺口恢复、三次握手、连接关闭、Dijkstra 候选距离更新；窗口图提供三个独立条件对比。演示由用户推进，无自动播放。正文包含手算例子、消息结构、对比表与展开式思考题，不以篇幅测试代替教学质量判断。

## 文件组织

- `frontend/src/content/chapterTutorials.ts`：通用内容类型、体系结构与 TCP 教程。
- `frontend/src/content/networkFoundations.ts`：其余 6 章教程。
- `frontend/src/content/networkExamples.ts`：字节分段、窗口与路由演示的数据计算。
- `frontend/src/components/ChapterTutorial.vue`：连续阅读、目录、思考题与参考资料。
- `frontend/src/components/NetworkMechanismFigure.vue`：精确 SVG 与步骤控制。
- `frontend/src/views/ChapterLessonView.vue`：按章节接入，其他课程保留原展示。
